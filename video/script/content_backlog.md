# QuantShield 潜在内容清单

> 用途：沉淀后续可以开发、拍摄、复盘和发布的内容方向。每个选题都尽量围绕“散户真实痛点 -> 风险防控功能 -> 数据/AI 实现 -> 投资者教育表达”展开。

## 内容定位

QuantShield 的视频内容不以荐股、预测涨跌或承诺收益为核心，而是记录一个开发者如何用数据、AI Agent 和风控方法，搭建面向 A 股散户的风险防控工具。

固定表达边界：

- 只展示工具开发、数据分析和历史复盘过程。
- 不给出任何具体买卖建议。
- 不承诺规避亏损或稳定盈利。
- 涉及个股时优先使用历史案例、公开信息和风险信号演示。
- 每期保留风险提示：本内容仅用于技术研究与投资者教育，不构成投资建议。

## 第一阶段：项目启动与人设建立

### 1. 我为什么要做 QuantShield

核心痛点：散户往往不是输在不知道机会，而是输在看不见风险。

可展示内容：

- 项目愿景：不预测涨跌，只量化风险。
- 散户常见踩坑场景：追热点、高位接盘、财报暴雷、消息误判、情绪化交易。
- 工具定位：A 股风险雷达、公告风险扫描、热点拥挤度监控、市场情绪看板。

### 2. 散户炒股最容易忽略的五类风险

核心痛点：很多亏损不是单一因素导致，而是多个风险信号叠加。

可展示内容：

- 财务风险：利润异常、现金流恶化、商誉减值、应收账款异常。
- 交易风险：放量滞涨、缩量反弹、高换手、高波动。
- 舆情风险：利好过度传播、股吧情绪极端、热点叙事反转。
- 政策风险：行业监管变化、补贴退坡、产业政策边际变化。
- 估值风险：估值分位过高、业绩预期跟不上价格。

### 3. 用一个项目记录 AI 投研工具的诞生

核心痛点：大多数人只看到结论，看不到一个分析工具如何一步步建立。

可展示内容：

- 当前项目目录结构。
- 后续功能路线图。
- 数据、模型、Agent、Dashboard、视频流水线之间的关系。
- 为什么先做风险系统，而不是直接做交易系统。

## 第二阶段：数据采集与指标构建

### 4. A 股数据到底从哪里来

核心痛点：没有稳定数据源，任何 AI 分析都会变成空中楼阁。

可展示内容：

- 行情数据：指数、个股、行业、成交额、涨跌家数。
- 基本面数据：财报、估值、分红、股东变化。
- 公告数据：减持、问询函、诉讼、质押、业绩预告。
- 舆情数据：新闻、股吧、社交平台热度。
- 数据源合规提醒：优先使用公开、授权或本地个人研究可用的数据。

### 5. 我先做了一个市场宽度指标

核心痛点：指数上涨不代表多数股票赚钱。

可展示内容：

- 上涨家数、下跌家数、涨停家数、跌停家数。
- 指数涨跌与个股中位数涨跌对比。
- “指数没跌，账户很疼”的原因。
- 输出一个每日市场健康度评分。

### 6. 热点拥挤度怎么量化

核心痛点：散户容易在主题最热的时候进场。

可展示内容：

- 板块成交额占比。
- 板块换手率。
- 近 N 日涨幅与波动率。
- 新闻热度和社交讨论热度。
- 拥挤度过高时不等于立刻下跌，但意味着风险收益比变差。

### 7. 用公告扫描潜在暴雷信号

核心痛点：很多风险其实提前写在公告里，但普通人没时间逐条读。

可展示内容：

- 公告类型：问询函、监管函、减持、质押、诉讼、业绩预告修正。
- LLM 提取风险关键词和事实证据。
- 给公告打风险标签。
- 输出“今日公告风险榜”。

## 第三阶段：AI Agent 风险分析

### 8. 让 AI Agent 扮演风险分析师

核心痛点：单次问答式大模型容易遗漏证据和反方观点。

可展示内容：

- 宏观 Agent：看政策、利率、汇率、经济数据。
- 市场 Agent：看指数、资金、成交、波动。
- 行业 Agent：看估值、拥挤度、景气度。
- 公告 Agent：看公司事件风险。
- 主编 Agent：整合结论，生成日报。

### 9. 大模型读公告靠谱吗

核心痛点：LLM 可能幻觉，所以必须让它基于证据输出。

可展示内容：

- 输入原始公告文本。
- 要求模型只引用公告中的事实。
- 输出风险标签、证据句、置信度和待确认问题。
- 对比“直接总结”和“结构化抽取”的差异。

### 10. 用多 Agent 辩论一个市场风险问题

核心痛点：市场判断经常存在多种解释，单一视角容易偏。

可展示内容：

- 乐观 Agent：列出支撑市场的证据。
- 悲观 Agent：列出潜在风险证据。
- 风控 Agent：只关心下行风险和仓位暴露。
- 裁判 Agent：输出风险等级和关键观察指标。

## 第四阶段：风控模型与历史复盘

### 11. 量化风控不是预测，而是知道自己可能亏多少

核心痛点：散户常常只想收益，不知道最大回撤意味着什么。

可展示内容：

- 波动率、最大回撤、VaR、CVaR 的直观解释。
- 用历史行情展示风险指标变化。
- 为什么同样涨幅的股票，风险可能完全不同。

### 12. 暴雷前有没有共同信号

核心痛点：市场中的风险事件可能有部分前置信号。

可展示内容：

- 历史案例复盘。
- 财务指标异常。
- 公告风险频率上升。
- 股价与成交异常。
- 舆情从乐观转向质疑。

### 13. 高股息策略也有风险吗

核心痛点：低风险标签可能让投资者忽视估值和业绩变化。

可展示内容：

- 股息率与股价下跌的关系。
- 分红可持续性。
- 现金流和负债压力。
- 行业拥挤度。

### 14. 为什么热门赛道最需要风险雷达

核心痛点：越是共识强的方向，越容易出现估值和交易拥挤风险。

可展示内容：

- 热点板块生命周期。
- 利好密度与价格反应。
- 拥挤交易的风险。
- 如何用数据识别情绪过热。

## 第五阶段：产品功能演示

### 15. 每天自动生成一份 A 股风险简报

核心痛点：散户缺少一份可快速阅读的风险摘要。

可展示内容：

- 今日市场风险等级。
- 风险上升的行业。
- 需要关注的公告事件。
- 热点拥挤度变化。
- 明日观察指标。

### 16. 做一个行业风险排行榜

核心痛点：投资者知道热点在哪，却不知道风险在哪。

可展示内容：

- 行业涨幅。
- 估值分位。
- 成交额占比。
- 波动率。
- 新闻热度。
- 综合风险评分。

### 17. 给个股生成风险画像

核心痛点：很多个股风险分散在财报、公告、行情和舆情里。

可展示内容：

- 公司基本信息。
- 财务风险标签。
- 公告事件风险。
- 交易异常。
- 舆情变化。
- 最终输出风险摘要，而不是买卖建议。

### 18. 把风险系统做成 Dashboard

核心痛点：文本报告适合阅读，仪表盘适合监控。

可展示内容：

- 市场总览。
- 行业风险热力图。
- 公告风险列表。
- 热点拥挤度曲线。
- Agent 自动摘要。

## 第六阶段：视频自动化流水线

### 19. 让 AI 自动生成财经短视频脚本

核心痛点：每天选题、写稿、配图、剪辑很耗时。

可展示内容：

- 从风险简报中选择主题。
- 生成标题、开头钩子、正文、结尾提示。
- 自动生成分镜和字幕。
- 人工审核后发布。

### 20. 用数据图表提升金融内容可信度

核心痛点：纯口播容易显得空泛，图表能增强证据感。

可展示内容：

- 市场宽度图。
- 热点拥挤度曲线。
- 行业风险雷达图。
- 公告风险标签卡片。
- 竖屏视频中的图表排版。

### 21. 我用 Agent 做了一个“财经主编”

核心痛点：每天最难的是判断该讲什么。

可展示内容：

- 输入市场数据、公告、新闻和舆情。
- 主编 Agent 输出三个候选选题。
- 根据风险价值、传播潜力、合规风险打分。
- 选择最适合发布的一期。

## 可落地的工具脚本方向

这些内容可以逐步变成 `scripts/` 目录下的实际工具脚本：

- `fetch_market_snapshot.py`：采集指数、行业、成交额、涨跌家数等市场快照。
- `fetch_announcements.py`：采集上市公司公告和监管问询信息。
- `build_market_breadth.py`：计算市场宽度、涨跌分布和赚钱效应指标。
- `build_hotspot_crowding.py`：计算板块热度和交易拥挤度。
- `extract_announcement_risks.py`：调用 LLM 从公告中抽取风险标签和证据。
- `generate_daily_risk_brief.py`：生成每日 A 股风险简报。
- `generate_video_topics.py`：从风险简报中生成短视频选题。
- `generate_video_script.py`：生成抖音口播稿、分镜、标题和字幕草稿。
- `render_risk_charts.py`：生成短视频中可使用的图表素材。
- `compose_short_video.py`：合成语音、字幕、图表和背景素材。

## 优先级建议

### P0：最先验证内容价值

- 项目启动视频。
- 散户风险痛点拆解。
- 市场宽度指标。
- 热点拥挤度指标。
- 每日风险简报雏形。

### P1：建立工具可信度

- 公告风险扫描。
- 个股风险画像。
- 行业风险排行榜。
- 多 Agent 风险辩论。
- 历史暴雷案例复盘。

### P2：形成自动化生产能力

- 自动生成选题。
- 自动生成视频脚本。
- 自动生成图表。
- 自动生成日报。
- Dashboard 展示。

### P3：形成转化闭环

- 免费短视频吸粉。
- 每日风险简报沉淀到公众号或社群。
- Dashboard 作为产品展示入口。
- 高阶报告或企业工具作为后续商业化方向。
